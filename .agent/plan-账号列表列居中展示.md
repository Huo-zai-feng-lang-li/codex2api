# 账号列表列居中展示

## 目标
- 将账号管理桌面表格的列头和列内容居中展示。
- 只影响账号页桌面表格，不改全局 Table 组件，不影响移动卡片和其他页面表格。

## 关键文件
- `frontend/src/pages/Accounts.tsx`

## 执行方案
- 在账号页定义本页专用表格对齐 class。
- 表头、选择框、序号、账号名称、标签、分组、计划、状态、请求、用量、费用、导入时间、更新时间、操作列统一居中。
- 复杂内容通过内部 flex/grid 容器居中，保留原有宽度与换行能力。

## 验证
- `pnpm typecheck`
- `pnpm build`
- 浏览器打开账号页检查列居中、无明显重叠、控制台无新增错误。
